How to create clusters using this config
Cluster A
KIND_EXPERIMENTAL_DOCKER_NETWORK=kind-net-a \
kind create cluster --name cluster-a --config kind-config.yaml

Cluster B
KIND_EXPERIMENTAL_DOCKER_NETWORK=kind-net-b \
kind create cluster --name cluster-b --config kind-config.yaml

Cluster C
KIND_EXPERIMENTAL_DOCKER_NETWORK=kind-net-c \
kind create cluster --name cluster-c --config kind-config.yaml


kubectl --context=kind-cluster-a exec -n spire sts/spire-server -- \
  /opt/spire/bin/spire-server bundle show -format spiffe > cluster-a-bundle.pem

2. Add federated bundles to cluster-b

Assume you already have the bundle files:

cluster-a-bundle.pem → bundle from cluster-a (bb-team.org)

cluster-c-bundle.pem → bundle from cluster-c (devops-team.org)

Now run these commands:

# Add cluster-a's bundle (bb-team.org)
kubectl --context=kind-cluster-b exec -i -n spire sts/spire-server -- \
  /opt/spire/bin/spire-server bundle set -format spiffe \
  -id spiffe://bb-team.org - < cluster-a-bundle.pem

# Add cluster-c's bundle (devops-team.org)
kubectl --context=kind-cluster-b exec -i -n spire sts/spire-server -- \
  /opt/spire/bin/spire-server bundle set -format spiffe \
  -id spiffe://devops-team.org - < cluster-c-bundle.pem
